# Recipe book handwriting

The mugwort left page is the user's original bitmap. Its original font is unknown.
The live recipe pages use handwriting fonts selected to resemble that artwork:

- `RecipeHandwriting.ttf`: unmodified Nanum Pen Script Regular.
- `RecipeBrushTitle.ttf`: unmodified Nanum Brush Script Regular.

Only the asset filenames are aliases; the fonts' internal names and bytes are unchanged.
